# 《教你手搓 Openpilot PC 版 · 软件篇》整理

> 来源：微信公众号文章（2026 年，作者「Septemberend」），配合《硬件篇》《车型适配篇》看。
> 本文只做**要点提炼 + 本机差异**，原教程以官方 24.04 原版镜像为准。

## 一、前提与硬件

- PC 版 openpilot **必须跑在物理机 Ubuntu 24 系统上**（虚拟机/容器不行，要直通摄像头与串口）。
- U 盘：纯净系统 8G 够；带环境/编译产物的镜像建议 32～64G。
- 主机：小主机（文中以极魔客 K8 为例）或笔记本均可，可双系统也可单 Ubuntu。
- BIOS：设「来电开机」（Advanced → Auto Power On → Power on）；K8 不能开机选启动项，只能改 BIOS 启动顺序。

## 二、安装系统

1. 镜像两种来源：
   - **官方原版**：`https://releases.ubuntu.com/24.04.x/...desktop-amd64.iso`（干净，需自己配环境）。
   - **民间修改版**（systemback 导出）：基础版（含常用配置/软件）与 op 版（含编译好的 cpv8/cpv9、AMD OpenCL 驱动、教程）。
2. 刻盘：**Rufus**（每次都要格式化、只能刻一个系统）或 **Ventoy**（首次格式化后，以后复制镜像即可）。
3. 安装时注意：
   - 笔记本勾选「**自动更新并安装驱动**」；小主机通常要自己装。
   - 勾选「**自动登录**」（有这一项的话）。

## 三、系统配置（不做也能跑，但体验差）

## 四、OpenCL 驱动（最容易翻车的一节）

- PC 版 op 主要用 **OpenCL 做推理**；驱动没装对，op 能启动但**不会推理**，务必先验证。
- 验证命令：`clinfo -l`
  - 没输出 / 只有 ICD loader 几行 → **没装好**。
  - 正常应看到 `Platform #0: ...` 与 `-- Device #0: ...`（AMD 是 `gfx1103` 之类；Intel 核显是 `Intel(R) UHD Graphics 620`）。
- AMD 显卡：文中给了 `install_rocm_opencl.sh`（ROCm 7.2.2 / Ubuntu 24.04），装完把用户加进 `video,render` 组。
- **本机是 Intel 核显**：不用 ROCm，装 `intel-opencl-icd` + `clinfo` 即可（本机已装好，识别为 UHD 620）。

## 六、编译三部曲

```bash
git clone https://gitee.com/huheas/carrotpilot.git cpv8
cd cpv8
# 依赖镜像（文中给的是阿里云/ghfast，本机实际改用清华 PyPI，见下）
export UV_Installer_GHE__Base_URL="https://ghfast.top/https://github.com"
export UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple
export EXTRA_INDEX_URL=https://mirrors.aliyun.com/pypi/simple
export UV_HTTP_TIMEOUT=600
export PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple
export PIP_TRUSTED_HOST=mirrors.aliyun.com

tools/op.sh setup     # 装系统依赖 + uv sync
tools/op.sh venv      # 进虚拟环境（或 source .venv/bin/activate）
tools/op.sh build     # 等价 scons -u -j$(nproc)
```

## 七、运行

```bash
export FINGERPRINT="BYD_TANG_DMI_23"           # 车型指纹
source .venv/bin/activate

# 单摄（仅长焦）
USE_WEBCAM=1 ROAD_CAM=0 NO_DM=1 system/manager/manager.py
# 双摄（目前无法自动切换）
USE_WEBCAM=1 ROAD_CAM=0 WIDE_CAM=2 NO_DM=1 system/manager/manager.py
```

**摄像头编号排查**：拔掉所有摄像头 → `ls /dev/video*` → 插上目标摄像头 → 再 `ls`，新增的那个编号就是 `ROAD_CAM` 的值。

**正式运行脚本** `run_23tang.sh`：把 `PARAMS_ROOT`/`LOG_ROOT` 指到 op 目录内（避免 home 权限/空间问题），
再 `cd op目录 && source .venv/bin/activate && USE_WEBCAM=1 ... manager.py`。

**做桌面图标**：写 `cpv8.desktop`（`Exec=gnome-terminal -e "bash -c '(脚本);$SHELL'"`、`Icon=.../img_chffr_wheel.png`），
复制到 `/usr/share/applications`。**开机自启**：把同样的命令丢进 `~/.config/autostart/`。

## 八、注意事项（原文强调）

1. 关闭 op 必须**终端里 Ctrl+C**；界面上点 × 没用（黑熊尤其不能直接断电）。
2. 黑熊挂了进 DFU 刷固件：`cd op目录 && source .venv/bin/activate && ./panda/board/recover.py`。
3. 车一启动就会跟着开机 → 调试完成后可以不带键鼠。
4. 比亚迪 + cpv8：P 档时按方向盘「取消巡航」可关闭小主机。
5. helper 注入（胜达 V9）参考《“天神之眼-D”来了》，helper 工具在 QQ 群文件。

## 十、常见问题速查

| 现象 | 处理 |
| --- | --- |
| `clinfo -l` 没输出 | OpenCL 驱动没装好（Intel 装 `intel-opencl-icd`） |
| `tools/op.sh` 报 Incompatible Ubuntu version | 改 `tools/op.sh` 的 `op_check_os` 白名单（本机已加 `resolute`） |
| uv 装依赖 403 | 换清华 PyPI |
| 找不到 `scons` | 先 `source .venv/bin/activate`（scons 装在 venv 里） |
| 摄像头打不开 | `ls /dev/video*` 对编号，或换 USB 口 |
| `manager.py` 一堆设备报错 | 正常——没接黑熊/摄像头时必然报错，硬件到位再跑 |
